# Titan Waste Management and Landfill Website

## Overview

This project is a professional multi-page business website developed for **Titan Waste Management and Landfill**, a South African waste management company focused on delivering reliable environmental and waste management services.

The website was designed using only **HTML5** and **CSS3** while following modern web development best practices such as responsive design, semantic HTML structure, accessibility standards, and reusable styling techniques.

The purpose of this website is to present the company professionally for:

- Municipal tenders
- Corporate clients
- Residential communities
- Environmental projects
- Public institutions
- Commercial and industrial services
